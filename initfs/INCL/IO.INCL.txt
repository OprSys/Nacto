INCLUDE /INCL/MEM

@IO_PRINTCHAR
- Description: Prints a single character.
- Param x1: The ASCII code to print.
PSTORE x1 0 0
SETVAL 0 1
SETVAL 1 0
SETVAL 2 0
SYSCALL
RET
@\

@IO_GETCHAR
- Description: Gets input and puts the ASCII value into x0.
- Return x0: The ASCII value read.
SETVAL 0 2
SETVAL 1 0
SETVAL 2 0
SYSCALL
PLOAD 0 0 0
RET
@\

@IO_GETSTR
- Description: Gets input and stores a string into a highslot in LRAM, up to newline.
- Param x1: The highslot to store the string into.
- Param x2: Whether to echo characters when typed. Non-zero to echo.
- Note: Modifies x3, incremented through the string, left at the position after the last character on return. Tells the length of the string.
SETVAL 3 0
SETVAL 5 x1
SETVAL 6 x2
SETVAL 3 0
GO IO_GETCHAR
SETVAL 7 x0
JNZ x6 +3
SETVAL 1 x7
GO IO_PRINTCHAR
JEQ x7 10 +4
PSTORE x7 x5 x3
ADD 3 x3 1
JMP -8
SETVAL 5 0
SETVAL 6 0
RET
@\

@IO_PRINTSTR
- Description: Prints a full string from a highslot in LRAM.
- Param x1: The highslot to read from.
- Note: Modifies x3, incremented through the string, left at the end position on return. Tells the length of the string.
SETVAL 5 x1
GO MEM_AUTOLEN
SETVAL 6 x0
SETVAL 3 0
PLOAD 0 x5 x3
SETVAL 7 x0
SETVAL 1 x7
GO IO_PRINTCHAR
ADD 3 x3 1
JEQ x3 x6 +2
JMP -6
SETVAL 5 0
SETVAL 6 0
SETVAL 0 0
RET
@\
