SYSCALL - DESCRIPTION
    Invokes Nacto for API access and other primitive calls.

SYSCALL - SYNTAX
    SYSCALL

SYSCALL - OPERANDS
    SYSCALL has no operands.

SYSCALL - POSSIBLE ERRORS
    Mixed

SYSCALL - GOTCHAS
    1.
        SYSCALL uses register 0 to specify what system action to invoke, and the rest (register 1 to 7) for parameters, not operands.

SYSCALL - EXAMPLES
    1. Print the character 'A' using SYSCALL. Register 0 = system call number (1 = SYSC_PRINT). Registers 1-7 are arguments.
        @PRIOR
        SETVAL 0 1
        SETVAL 1 1
        SETVAL 2 0
        STORE 65 1 0
        SYSCALL
        HALT
        @\
