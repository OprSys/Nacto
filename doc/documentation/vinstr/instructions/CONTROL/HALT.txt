HALT - DESCRIPTION
    Halts the program.

HALT - SYNTAX
    HALT

HALT - OPERANDS
    HALT does not have any operands.

HALT - POSSIBLE ERRORS
    HALT does not throw any errors.

HALT - GOTCHAS
    HALT has no gotchas.

HALT - EXAMPLES
    1. Unconditional program. Computes a value and halts.
        @PRIOR
        SETVAL 0 5
        ADD 0 x0 5
        SUB 0 x0 2
        HALT
        @\
    2. Conditional program. Register 0 is the flag. Since register 0 is 0, JZ triggers and skips the debug dump.
        @PRIOR
        SETVAL 0 0
        JZ 0 +2
        DEBUGRAMDUMP
        HALT
        @\
    3. Debug dump then halt.
        @PRIOR
        DEBUGPROCDUMP
        HALT
        @\
