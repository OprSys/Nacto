JEQ - DESCRIPTION
    Jumps to a specified program counter, if a value is equal to another value.

JEQ - SYNTAX
    JEQ <val1> <val2> <pc>

JEQ - OPERANDS
    val1
        The first value for check.
    val2
        The second value for check.
    pc
        The program counter to jump to.

JEQ - POSSIBLE ERRORS
    JEQ does not throw any errors.

JEQ - GOTCHAS
    1.
        Note that JEQ uses the logic of JMP internally to jump. So, rules for JMP also applies to JEQ.

JEQ - EXAMPLES
    1. Compare two equal values. JEQ triggers, jumping over the debug dump.
        @PRIOR
        JEQ 5 5 +2
        DEBUGVMREGDUMP
        HALT
        @\
    2. Compare two unequal values. JEQ does not trigger, falls through.
        @PRIOR
        JEQ 5 6 +2
        DEBUGVMREGDUMP
        HALT
        @\
