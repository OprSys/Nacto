JZ - DESCRIPTION
    Jumps to a specified program counter, if a register is equal to 0.

JZ - SYNTAX
    JZ <reg to check> <pc>

JZ - OPERANDS
    reg to check
        The register to check if it is 0 or not.
    pc
        The program counter to jump to.

JZ - POSSIBLE ERRORS
    JZ does not throw any errors.

JZ - GOTCHAS
    1.
        Note that JZ uses the logic of JMP internally to jump. So, rules for JMP also applies to JZ.

JZ - EXAMPLES
    1. If register 0 is zero, skip the debug dump.
        @PRIOR
        SETVAL 0 0
        JZ 0 +2
        DEBUGRAMDUMP
        HALT
        @\
    2. If register 0 is not zero, JZ does not trigger and falls through.
        @PRIOR
        SETVAL 0 1
        JZ 0 +2
        DEBUGRAMDUMP
        HALT
        @\

JZ - SEE ALSO
    N/A
