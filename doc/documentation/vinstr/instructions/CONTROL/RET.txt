RET - DESCRIPTION
    Jumps back to a prior GO call.

RET - SYNTAX
    RET

RET - OPERANDS
    RET does not have any operands.

RET - POSSIBLE ERRORS
    1;13 - CPU_NOPRIORGO
        No prior GO instructions were executed.

RET - GOTCHAS
    RET has no gotchas.

RET - EXAMPLES
    1. Call TESTNT via GO, execute its code, then return and halt.
        @PRIOR
        GO TESTNT
        HALT
        @\

        @TESTNT
        DEBUGVMREGDUMP
        RET
        @\
