DIV - DESCRIPTION
    Takes two values, divides them, then assigns the result to a register.

DIV - SYNTAX
    DIV <reg to put result> <val1> <val2>

DIV - OPERANDS
    reg to put result
        The specified register to store the result.
    val1
        The first number in use for the operation.
    val2
        The second number in use for the operation.

DIV - POSSIBLE ERRORS
    1;2 - CPU_DIVBYZERO
        Division by zero.
    1;7 - CPU_OOB
        Register index out of bounds.
    1;8 - CPU_LIMEXC
        Value not in LIM_MINIMUM-LIM_MAXIMUM.

DIV - GOTCHAS
    1.
        Note that DIV uses the logic of SETVAL internally to set the register value. So, rules for SETVAL also applies to DIV.
    2.
        DIV uses floor-division. Decimals do not exist in VINSTR.

DIV - EXAMPLES
    1.
        - Divide using literals, then store in register 0.
        - Result is 10.
        DIV 0 100 10
        HALT
    2.
        - Divide using registers, then store in register 0.
        - Result is 10.
        SETVAL 1 100
        SETVAL 2 10
        DIV 0 x1 x2
        HALT
