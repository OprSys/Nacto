SETVAL - DESCRIPTION
    Takes a register and assigns it a value.

SETVAL - SYNTAX
    SETVAL <reg> <val>

SETVAL - OPERANDS
    reg
        The register to assign to.
    val
        The value (an integer) to give to the specified register (reg).

SETVAL - POSSIBLE ERRORS
    1;7 - CPU_OOB
        Register index out of bounds.
    1;8 - CPU_LIMEXC
        Value not in LIM_MINIMUM-LIM_MAXIMUM.

SETVAL - GOTCHAS
    1.
        If your intent is to, for example, give the register 0 the value 46, then "SETVAL x0 46" would be incorrect. If no prior instructions are in this register, then sure, it would succeed, but not in the way you think. `x0` would check the value of register 0, which by default would be 0 ("SETVAL 0 46"). However, you should only use `x` syntax for when you need to use the value of another register. For here, you only need to reference a register, not obtain its value. So, you would do "SETVAL 0 46".

SETVAL - EXAMPLES
    1. Sets register 0 with the value 5.
        @PRIOR
        SETVAL 0 5
        HALT
        @\
    2. Grabs the value of a register and duplicates it to another.
        @PRIOR
        SETVAL 1 5
        SETVAL 0 x1
        HALT
        @\
