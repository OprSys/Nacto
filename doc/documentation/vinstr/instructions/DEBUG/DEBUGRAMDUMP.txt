DEBUGRAMDUMP - DESCRIPTION
    Debug instruction. Prints the full RAM object to stdout.

DEBUGRAMDUMP - SYNTAX
    DEBUGRAMDUMP

DEBUGRAMDUMP - OPERANDS
    DEBUGRAMDUMP does not have any operands.

DEBUGRAMDUMP - POSSIBLE ERRORS
    DEBUGRAMDUMP does not throw any errors.

DEBUGRAMDUMP - GOTCHAS
    DEBUGRAMDUMP has no gotchas.

DEBUGRAMDUMP - EXAMPLES
    1. Dump the full RAM object.
        @PRIOR
        DEBUGRAMDUMP
        HALT
        @\
