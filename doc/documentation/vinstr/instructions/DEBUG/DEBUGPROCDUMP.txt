DEBUGPROCDUMP - DESCRIPTION
    Debug instruction. Prints the entire currently running process to stdout.

DEBUGPROCDUMP - SYNTAX
    DEBUGPROCDUMP

DEBUGPROCDUMP - OPERANDS
    DEBUGPROCDUMP does not have any operands.

DEBUGPROCDUMP - POSSIBLE ERRORS
    DEBUGPROCDUMP does not throw any errors.

DEBUGPROCDUMP - GOTCHAS
    DEBUGPROCDUMP has no gotchas.

DEBUGPROCDUMP - EXAMPLES
    1. Dump the entire current process state.
        @PRIOR
        DEBUGPROCDUMP
        HALT
        @\
