DEBUGVMREGDUMP - DESCRIPTION
    Debug instruction. Prints the VM array of the current process to stdout.

DEBUGVMREGDUMP - SYNTAX
    DEBUGVMREGDUMP

DEBUGVMREGDUMP - OPERANDS
    DEBUGVMREGDUMP does not have any operands.

DEBUGVMREGDUMP - POSSIBLE ERRORS
    DEBUGVMREGDUMP does not throw any errors.

DEBUGVMREGDUMP - GOTCHAS
    DEBUGVMREGDUMP has no gotchas.

DEBUGVMREGDUMP - EXAMPLES
    1. Dump the VM register array of the current process.
        @PRIOR
        DEBUGVMREGDUMP
        HALT
        @\
