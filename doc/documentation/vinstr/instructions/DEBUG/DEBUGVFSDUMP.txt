DEBUGVFSDUMP - DESCRIPTION
    Debug instruction. Prints the entire virtual file system tree to stdout.

DEBUGVFSDUMP - SYNTAX
    DEBUGVFSDUMP

DEBUGVFSDUMP - OPERANDS
    DEBUGVFSDUMP does not have any operands.

DEBUGVFSDUMP - POSSIBLE ERRORS
    DEBUGVFSDUMP does not throw any errors.

DEBUGVFSDUMP - GOTCHAS
    DEBUGVFSDUMP has no gotchas.

DEBUGVFSDUMP - EXAMPLES
    1. Dump the entire virtual file system tree.
        @PRIOR
        DEBUGVFSDUMP
        HALT
        @\
