PLOAD - DESCRIPTION
    Loads a value from LRAM.

PLOAD - SYNTAX
    PLOAD <reg> <highslot> <lowslot>

PLOAD - OPERANDS
    reg
        The register to load from LRAM.
    highslot
        The top level of LRAM to specify.
    lowslot
        The bottom level of LRAM to specify.

PLOAD - POSSIBLE ERRORS
    BinaryError.OutOfBounds
        If highslot or lowslot exceeds the space of LRAM, this will be raised.
    BinaryError.LimitExceeded
        If the register to load into is lower than LIM_MINIMUM or higher than LIM_MAXIMUM, this will be raised.

PLOAD - GOTCHAS
    1.
        Note that LRAM slots are accessed as 0-indices.

PLOAD - EXAMPLES
    1.
        - Loads LRAM[0][0] (being 45) into register 0.
        PSTORE 45 0 0
        PLOAD 0 0 0
        HALT
