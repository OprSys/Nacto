DATA - DESCRIPTION
    Sets a specified list of lowslots in a highslot with values, in positional order.

DATA - SYNTAX
    DATA <highslot> <count to reg> <[lowslots]...>

DATA - OPERANDS
    highslot
        Which highslot to fill.
    count to reg
        A register specifying where to put the count of how much values were written.
    [lowslots]...
        Each lowslot to write to in the highslot.

DATA - POSSIBLE ERRORS
    placeholder

DATA - GOTCHAS
    1.
        For each value in lowslots, will map directly to LRAM lowslots. For example, `DATA 1 4 65 65 65` will set LRAM[1][0..2] to 65, also being 'A'.

DATA - EXAMPLES
    1.
        - Print "Hello, World!".
        INCLUDE /INCL/IO
        DATA 0 3 72 101 108 108 111 44 32 87 111 114 108 100 33
        ICALL IO_PRINTSTR HIGHSLOT:0 LENGTH:x3
        HALT
