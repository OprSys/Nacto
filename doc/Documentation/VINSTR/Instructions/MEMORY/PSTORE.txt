PSTORE - DESCRIPTION
    Sets a value in LRAM.

PSTORE - SYNTAX
    PSTORE <val> <highslot> <lowslot>

PSTORE - OPERANDS
    val
        The value to assign to LRAM.
    highslot
        The top level of LRAM to specify.
    lowslot
        The bottom level of LRAM to specify.

PSTORE - POSSIBLE ERRORS
    BinaryError.OutOfBounds
        If highslot or lowslot exceeds the space of LRAM, this will be raised.
    BinaryError.LimitExceeded
        If the value to assign is lower than LIM_MINIMUM or higher than LIM_MAXIMUM, this will be raised.

PSTORE - GOTCHAS
    1.
        Note that LRAM slots are accessed as 0-indices.

PSTORE - EXAMPLES
    1.
        - Set the LRAM slot LRAM[0][0] with 5.
        PSTORE 5 0 0
        HALT
