JMP - DESCRIPTION
    Jumps to a specified program counter.

JMP - SYNTAX
    JMP <pc>
    JMP +<offset>
    JMP -<offset>

JMP - OPERANDS
    pc
        The program counter to jump to (absolute, 0-indexed).
    +offset
        Jumps forward by offset lines from the current instruction.
    -offset
        Jumps backward by offset lines from the current instruction.

JMP - POSSIBLE ERRORS
    placeholder

JMP - GOTCHAS
    1.
        JMP uses a direct program counter number, NOT line number. To jump to the first instruction, you would do "JMP 0", not "JMP 1". In other terms, JMP is 0-indexed.
    2.
        Relative jumps (with + or -) are resolved at runtime relative to the JMP instruction's own position. This means code inside an INCLUDEd file can use relative jumps without being affected by the shift caused by inclusion.

JMP - EXAMPLES
    1.
        - Jump to the beginning of the program. HALT here would never happen.
        JMP 0
        HALT
    2.
        - Infinite loop until limit would be exeeded from ADD. HALT here would never happen.
        ADD 0 x0 1
        JMP 0
        HALT
    3.
        - Relative jump, skip the next instruction.
        JMP +1
        HALT
    4.
        - Relative jump, go back to the ADD instruction. This also will cause an infinite loop until limit would be exceeded from ADD.
        ADD 0 x0 1
        JMP -1
        HALT
