DIV - DESCRIPTION
    Takes two values, divides them, then assigns the result to a register.

DIV - SYNTAX
    DIV <reg to put result> <val1> <val2>

DIV - OPERANDS
    reg to put result - any
        The specified register to store the result.
    val1 - any
        The first number in use for the operation.
    val2 - any
        The second number in use for the operation.

DIV - POSSIBLE ERRORS
    BinaryError.OutOfBounds
        If the specified register is not in the range of the VM array, this will be raised.
    BinaryError.LimitExceeded
        If the result to assign is lower than LIM_MINIMUM or higher than LIM_MAXIMUM, this will be raised.
    BinaryError.DivisionByZero
        If val2 is zero, this is raised. You cannot divide by zero.

DIV - GOTCHAS
    1.
        Note that DIV uses the logic of SETVAL internally to set the register value. So, rules for SETVAL also applies to DIV.
    2.
        DIV uses floor-division. Decimals do not exist in VINSTR.

DIV - EXAMPLES
    1.
        - Divide using literals, then store in register 0.
        - Result is 10.
        DIV 0 100 10
        HALT
    2.
        - Divide using registers, then store in register 0.
        - Result is 10.
        SETVAL 1 100
        SETVAL 2 10
        DIV 0 x1 x2
        HALT
