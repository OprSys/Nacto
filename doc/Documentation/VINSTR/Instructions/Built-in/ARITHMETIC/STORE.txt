STORE - DESCRIPTION
    Sets a value in RAM.

STORE - SYNTAX
    STORE <val> <highslot> <lowslot>

STORE - OPERANDS
    val - any
        The value to assign to RAM.
    highslot - any
        The top level of RAM to specify.
    lowslot - any
        The bottom level of RAM to specify.

STORE - POSSIBLE ERRORS
    BinaryError.OutOfBounds
        If highslot or lowslot exceeds the space of RAM, this will be raised.
    BinaryError.LimitExceeded
        If the value to assign is lower than LIM_MINIMUM or higher than LIM_MAXIMUM, this will be raised.

STORE - GOTCHAS
    1.
        Note than RAM slots are accessed as 0-indices.

STORE - EXAMPLES
    1.
        - Set the RAM slot RAM[0][0] with 5.
        STORE 5 0 0
        HALT
