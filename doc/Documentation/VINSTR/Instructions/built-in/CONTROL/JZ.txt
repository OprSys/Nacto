JZ - DESCRIPTION
    Jumps to a specified program counter, if a register is equal to 0.

JZ - SYNTAX
    JZ <reg to check> <pc>

JZ - OPERANDS
    reg to check
        The register to check if it is 0 or not.
    pc
        The program counter to jump to.

JZ - POSSIBLE ERRORS
    BinaryError.OutOfBounds
        If the specified register is not in the range of the VM array, this will be raised.

JZ - GOTCHAS
    1.
        Note that JZ uses the logic of JMP internally to jump. So, rules for JMP also applies to JZ.
