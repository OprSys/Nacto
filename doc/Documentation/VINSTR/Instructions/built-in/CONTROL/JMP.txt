JMP - DESCRIPTION
    Jumps to a specified program counter.

JMP - SYNTAX
    JMP <pc>

JMP - OPERANDS
    pc
        The program counter to jump to.

JMP - POSSIBLE ERRORS
    JMP cannot error.

JMP - GOTCHAS
    1.
        JMP uses a direct program counter number, NOT line number. To jump to the first instruction, you would do "JMP 0", not "JMP 1". In other terms, JMP is 0-indexed.

JMP - EXAMPLES
    1.
        - Jump to the beginning of the program. HALT here would not ever happen.
        JMP 0
        HALT
    2.
        - Infinite loop until limit would be exeeded from ADD. HALT here would not ever happen.
        ADD 0 x0 1
        JMP 0
        HALT
