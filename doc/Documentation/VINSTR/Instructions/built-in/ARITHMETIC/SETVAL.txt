SETVAL - DESCRIPTION
    Takes a register and assigns it a value.

SETVAL - SYNTAX
    SETVAL <reg> <val>

SETVAL - OPERANDS
    reg
        The register to assign to.
    val
        The value (an integer) to give to the specified register (reg).

SETVAL - POSSIBLE ERRORS
    BinaryError.OutOfBounds
        If the specified register is not in the range of the VM array, this will be raised.
    BinaryError.LimitExceeded
        If the value to assign is lower than LIM_MINIMUM or higher than LIM_MAXIMUM, this will be raised.

SETVAL - GOTCHAS
    1.
        If your intent is to, for example, give the register 0 the value 46, then "SETVAL x0 46" would be incorrect. If no prior instructions are in this register, then sure, it would succeed, but not in the way you think. `x0` would check the value of register 0, which would be 0. ("SETVAL 0 46"). However, you should only use `x` syntax for when you need to use the value of another register. For here, you only need to reference a register, not obtain its value. So, you would do "SETVAL 0 46".

SETVAL - EXAMPLES
    1.
        - Sets register 0 with the value 5.
        SETVAL 0 5
        HALT
    2.
        - Grabs the value of a register and duplicates it to another.
        SETVAL 1 5
        SETVAL 0 x1
        HALT
