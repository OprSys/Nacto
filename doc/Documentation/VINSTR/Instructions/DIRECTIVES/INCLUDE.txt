INCLUDE - DESCRIPTION
    Pull in a `.incl` file and writes its contents into the caller program, at the current line.

INCLUDE - SYNTAX
    INCLUDE <vfs path to file>

INCLUDE - OPERANDS
    vfs path to file
        The file to include into the running program.

INCLUDE - POSSIBLE ERRORS
    placeholder

INCLUDE - GOTCHAS
    1.
        INCLUDE removes its own line, and replaces it with the includable file's content directly.

INCLUDE - EXAMPLES
    1.
        - Bring in the `io` lib.
        INCLUDE /INCL/IO
        - Use IO_PRINTCHAR (from /INCL/IO), with ASCII = 65. Prints 'A'.
        ICALL IO_PRINTCHAR ASCII:65
        HALT
