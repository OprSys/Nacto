IEND - DESCRIPTION
    Marks the end of definition for a custom instruction.

IEND - SYNTAX
    IEND

IEND - OPERANDS
    IEND does not have any operands.

IEND - POSSIBLE ERRORS
    BinaryError.InvalidInstruction
        If IEND is encountered outside of a custom instruction definition (i.e., without a preceding IDEF), this is raised.

IEND - GOTCHAS
    1.
        IEND is only valid when a custom instruction is being defined.
    2.
        When IEND is reached during execution of a custom instruction, control flow returns to the instruction immediately after the corresponding ICALL call.

IEND - EXAMPLES
    1.
        - Defines a simple instruction and uses IEND to mark its end.
        IDEF CUSTOMINSTR
        SETVAL 0 1
        IEND
    2.
        - Defines an instruction with arguments and uses IEND to mark its end.
        IDEF CUSTOMINSTR CUSTOMARG1 CUSTOMARG2
        SETVAL 0 $CUSTOMARG1
        SETVAL 1 $CUSTOMARG2
        IEND
